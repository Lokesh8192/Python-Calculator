# Python Calculator Application

## Project Overview

A menu-driven calculator application developed using Python. This application performs basic arithmetic operations using separate reusable functions.

## Technologies Used

- Python
- Pytest
- PyCharm

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Floor Division
- Modulus
- Exponentiation
- Input validation
- Exception handling
- Division-by-zero protection
- Automated testing

## How to Run

1. Clone or download the project.
2. Open the project directory.
3. Install pytest:

```bash
python -m pip install pytest
```

4. Run the calculator:

```bash
python Project_01_Calculator.py
```

## How to Run Tests

Execute:

```bash
python -m pytest -v
```
